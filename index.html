KALI COLD VAULT OS

Você está abrindo o código-fonte em React + TypeScript diretamente pelo arquivo local. Navegadores não executam arquivos .tsx sem compilação prévia.

Como usar o aplicativo:
🌐 1. GitHub Pages (Recomendado):
Acesse o link gerado pelo GitHub em Settings > Pages.
📦 2. Baixar a versão pronta (ZIP com dist):
No seu GitHub, vá em Actions > Deploy > Clique no último rodado > Artifacts > github-pages.
💻 3. Rodar localmente no computador:
Abra o terminal na pasta e rode:
npm install && npm run dev
